# 📝 Quizz

Projeto simples de quiz interativo desenvolvido exclusivamente para uma atividade prática da disciplina/projeto de **Modelagem de Dados**.

## 🎯 Objetivo

Servir como aplicação front-end de apoio para demonstrar a coleta e estruturação de respostas em uma atividade acadêmica de modelagem de dados.

## 🛠️ Tecnologias

- **HTML5**
- **CSS3**
- **JavaScript**

## 💻 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/mkzzo/Quizz.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador.
